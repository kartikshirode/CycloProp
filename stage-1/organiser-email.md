# Organiser questions, and what happened to them

Three questions were drafted on 26 August to unblock sizing. The official problem statement
turned up later the same day and dealt with all three, so none of them was ever sent. Kept as
the record of why, because "we asked the organisers nothing" reads differently once you can see
what there was to ask.

| Question | What answered it |
| --- | --- |
| Is thrust to weight measured on the module or the aircraft? | The problem statement, outright. "The complete cyclorotor module, including rotor blades, frame, pitch mechanism, motor, actuator, and associated mounting hardware" |
| What is the second objective? | Settled in substance. The problem statement gives one objective and the site's own structure text says "Teams work on a single objective". The FAQ note about confirming a second one is a stale draft left live on the page |
| Is there a detailed problem statement? | There is, and we have it. See [../context.md](../context.md) |

One question survives and it is about submission format, which the problem statement never
specifies: whether there is a page limit and a naming convention for the attachment. It is not
here any more. It rides at the end of the staged submission email in
[submission/email-draft.md](submission/email-draft.md), which is the mail that will actually be
sent, so asking it costs nothing extra. See D57.

The second question, whether a registration reference belongs in the document, was answered
outside this file when the reference was supplied on 1 September. The report's identity block
carries it and the question was dropped rather than asked. This page said two questions rode with
the submission and the draft asked one, which is the kind of disagreement that makes a reader
trust neither number.

Nothing on this page blocks anything. Sending mail to the organisers stays a human action and a
blocked trigger in [../.claude/weekly-loop.md](../.claude/weekly-loop.md), which is the execution
contract per D28.
